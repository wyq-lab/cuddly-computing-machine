## 程序设计基础

### 一、程序与程序设计语言

#### 1. 程序设计语言分类

| 类别 | 特点 | 举例 |
|------|------|------|
| 机器语言 | 二进制代码，直接执行 | 10001011… |
| 汇编语言 | 符号化机器指令，需汇编 | MOV AX, BX |
| 高级语言 | 接近自然语言，需编译/解释 | C、Java、Python、C++ |

#### 2. 高级语言的执行方式

- **编译执行**：将源程序一次性全部翻译为目标代码，再执行（C、C++、Go）
  - 优点：执行速度快
  - 缺点：跨平台性差
  
- **解释执行**：逐条翻译并执行源程序（Python、JavaScript、PHP）
  - 优点：跨平台性好，便于调试
  - 缺点：执行速度较慢

- **混合型**：先编译为中间代码，再解释执行（Java → 字节码 + JVM、C# → IL + CLR）

#### 3. 编译过程

源程序 → **词法分析** → **语法分析** → **语义分析** → 中间代码生成 → 代码优化 → **目标代码生成** → 目标程序

### 二、算法

#### 1. 算法的定义与特征

**算法是解决问题的方法和步骤的精确描述。**

**算法的五大特征：**
1. **有穷性**：在有限步骤后结束
2. **确定性**：每一步都有确切的含义
3. **可行性**：每一步都可以通过基本运算实现
4. **输入**：有0个或多个输入
5. **输出**：有1个或多个输出

#### 2. 算法复杂度

**（1）时间复杂度**
- 衡量算法执行时间随问题规模增长的变化趋势
- 用大O表示法：O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2ⁿ)

| 复杂度 | 名称 | 典型算法 |
|--------|------|---------|
| O(1) | 常数阶 | 数组按索引访问 |
| O(log n) | 对数阶 | 二分查找 |
| O(n) | 线性阶 | 顺序查找 |
| O(n log n) | 线性对数阶 | 归并排序、快速排序 |
| O(n²) | 平方阶 | 冒泡排序、插入排序 |

**（2）空间复杂度**
- 衡量算法执行所需存储空间的变化趋势

#### 3. 常见算法

**（1）排序算法**
- 冒泡排序：相邻比较交换，O(n²)，稳定
- 选择排序：每轮选最小/最大，O(n²)，不稳定
- 插入排序：构建有序序列，O(n²)，稳定
- 快速排序：分治思想，O(n log n)，不稳定
- 归并排序：分治合并，O(n log n)，稳定

**（2）查找算法**
- 顺序查找：逐个比较，O(n)
- 二分查找：有序序列折半查找，O(log n)

### 三、程序设计的三种基本结构

#### 1. 顺序结构
按语句书写顺序依次执行，是最基本的程序结构。

```
语句1；
语句2；
语句3；
```

#### 2. 选择结构（分支结构）
根据条件判断选择执行不同的语句。

- **单分支**：if (条件) { 语句 }
- **双分支**：if (条件) { 语句1 } else { 语句2 }
- **多分支**：switch/case 语句

#### 3. 循环结构
重复执行某段代码直到满足退出条件。

- **while 循环**（当型循环）：先判断后执行
- **do-while 循环**（直到型循环）：先执行后判断
- **for 循环**（计数型循环）：已知循环次数

**三大结构的特点**：只有一个入口，只有一个出口，结构内的每一部分都有机会被执行到。

### 四、数据结构基础

#### 1. 数据结构分类

| 类别 | 逻辑结构 | 物理结构（存储结构） |
|------|---------|-------------------|
| 含义 | 数据元素之间的逻辑关系 | 数据结构在计算机中的存储方式 |
| 类型 | 线性结构、非线性结构 | 顺序存储、链式存储 |

#### 2. 常见数据结构

**（1）线性表**
- 定义：n个数据元素的有限序列
- 存储方式：
  - 顺序存储（数组）：随机访问快，插入删除慢
  - 链式存储（链表）：插入删除快，随机访问慢

**（2）栈（Stack）**
- 特点：**后进先出（LIFO）**
- 操作：入栈（push）、出栈（pop）
- 应用：函数调用、表达式求值、括号匹配

**（3）队列（Queue）**
- 特点：**先进先出（FIFO）**
- 操作：入队（enqueue）、出队（dequeue）
- 应用：任务调度、打印队列、BFS

**（4）树（Tree）**
- 是n个节点的有限集合，具有层次关系的非线性结构
- **二叉树**：每个节点最多有两个子树
  - 第i层最多有 2^(i-1) 个节点
  - 深度为k的二叉树最多有 2^k - 1 个节点
- 遍历方式：前序遍历、中序遍历、后序遍历、层序遍历

**（5）图（Graph）**
- 由顶点和边组成的非线性结构
- 存储方式：邻接矩阵、邻接表
- 遍历：深度优先搜索（DFS）、广度优先搜索（BFS）

### 五、面向对象程序设计基础

#### 1. 面向对象三大特性

| 特性 | 含义 | 作用 |
|------|------|------|
| **封装** | 将数据和对数据的操作封装在一起 | 信息隐藏，提高安全性 |
| **继承** | 子类继承父类的属性和方法 | 代码复用，层次分类 |
| **多态** | 同一操作作用于不同对象产生不同行为 | 接口统一，灵活扩展 |

#### 2. 类与对象

- **类（Class）**：对具有共同属性和行为的一类事物的抽象描述
- **对象（Object）**：类的具体实例
