## 计算机网络基础

### 一、计算机网络概述

#### 1. 计算机网络的定义

**计算机网络是将地理上分散的、具有独立功能的计算机系统通过通信设备和线路连接起来，在网络协议控制下实现资源共享和信息传递的系统。**

#### 2. 计算机网络分类

| 分类方式 | 类型 | 说明 |
|---------|------|------|
| 覆盖范围 | LAN（局域网） | 小范围，如校园、办公室 |
| | MAN（城域网） | 城市范围 |
| | WAN（广域网） | 跨地区、跨国 |
| 拓扑结构 | 星型 | 中心节点连接所有节点 |
| | 总线型 | 所有节点共享一条总线 |
| | 环型 | 节点连接成闭合环 |
| | 树型 | 分层结构 |
| | 网状型 | 节点之间多点连接 |

### 二、计算机网络体系结构

#### 1. OSI七层模型（理论参考模型）

| 层次 | 名称 | 功能 | 典型协议/设备 |
|------|------|------|-------------|
| 7 | 应用层 | 为用户提供网络服务接口 | HTTP、FTP、SMTP、DNS |
| 6 | 表示层 | 数据格式转换、加密解密 | JPEG、MPEG、ASCII |
| 5 | 会话层 | 建立、管理和终止会话 | RPC、SQL |
| 4 | 传输层 | 端到端可靠/不可靠传输 | TCP、UDP |
| 3 | 网络层 | 路由选择、逻辑寻址 | IP、ICMP、路由器 |
| 2 | 数据链路层 | 帧封装、差错控制 | MAC、交换机、网桥 |
| 1 | 物理层 | 比特流传输 | 中继器、集线器、网线 |

**记忆口诀：All People Seem To Need Data Processing（从7到1）**

#### 2. TCP/IP四层模型（实际应用模型）

| TCP/IP层次 | 对应OSI层次 | 主要协议 |
|-----------|-----------|---------|
| 应用层 | 应用层+表示层+会话层 | HTTP、HTTPS、FTP、SMTP、DNS、Telnet |
| 传输层 | 传输层 | TCP、UDP |
| 网络层（网际层） | 网络层 | IP、ICMP、ARP、RARP |
| 网络接口层 | 数据链路层+物理层 | 以太网、WiFi |

**记忆口诀：应用传输网络接口**

#### 3. TCP vs UDP

| 对比维度 | TCP | UDP |
|---------|-----|-----|
| 连接方式 | 面向连接 | 无连接 |
| 可靠性 | 可靠（确认、重传） | 不可靠 |
| 速度 | 慢 | 快 |
| 适用场景 | 文件传输、网页、邮件 | 视频流、语音通话、DNS查询 |
| 三次握手 | 需要 | 不需要 |

**TCP三次握手过程：**
1. SYN：客户端 → 服务器（请求建立连接）
2. SYN+ACK：服务器 → 客户端（确认并请求）
3. ACK：客户端 → 服务器（确认）

### 三、IP地址与子网划分

#### 1. IP地址分类（IPv4）

IPv4地址由32位二进制组成，分4段，每段8位，用点分十进制表示。

| 类别 | 第一段范围 | 默认子网掩码 | 私有地址段 | 用途 |
|------|----------|------------|-----------|------|
| A类 | 1-126 | 255.0.0.0 | 10.0.0.0/8 | 大型网络 |
| B类 | 128-191 | 255.255.0.0 | 172.16.0.0/12 | 中型网络 |
| C类 | 192-223 | 255.255.255.0 | 192.168.0.0/16 | 小型网络 |
| D类 | 224-239 | — | — | 组播 |
| E类 | 240-255 | — | — | 保留 |

**特殊IP地址：**
- 127.0.0.1：本地回环地址（localhost）
- 169.254.x.x：DHCP获取失败时自动分配
- 0.0.0.0：本机所有IP地址

#### 2. 子网掩码与子网划分

**子网掩码**用于区分IP地址中的网络位和主机位。

- IP地址 AND 子网掩码 = 网络地址
- 子网划分借位公式：可用子网数 = 2^n - 2（n为借位位数）或不减2（取决于设备支持）

#### 3. IPv6

- 地址长度：128位，8组16进制数
- 格式：2001:0db8:85a3:0000:0000:8a2e:0370:7334
- 优势：地址空间大、安全性高、支持自动配置

### 四、常见网络协议

| 协议 | 全称 | 端口 | 功能 |
|------|------|------|------|
| HTTP | 超文本传输协议 | 80 | Web浏览 |
| HTTPS | 超文本传输安全协议 | 443 | 加密Web通信 |
| FTP | 文件传输协议 | 20/21 | 文件上传下载 |
| SMTP | 简单邮件传输协议 | 25 | 发送邮件 |
| POP3 | 邮局协议v3 | 110 | 接收邮件 |
| DNS | 域名系统 | 53 | 域名→IP转换 |
| DHCP | 动态主机配置协议 | 67/68 | 自动分配IP |
| Telnet | 远程登录 | 23 | 远程管理 |
| SSH | 安全外壳 | 22 | 加密远程登录 |

#### DNS域名解析过程

1. 用户输入域名（如：www.baidu.com）
2. 查询本地DNS缓存
3. 查询本地hosts文件
4. 查询本地DNS服务器
5. 逐级向上：根DNS → 顶级域DNS → 权威DNS
6. 返回IP地址

### 五、网络安全基础

#### 1. 常见网络攻击

| 攻击类型 | 方式 | 防范措施 |
|---------|------|---------|
| DoS/DDos | 大量请求耗尽资源 | 防火墙、流量清洗 |
| SQL注入 | 恶意SQL代码 | 参数化查询、输入校验 |
| XSS跨站脚本 | 注入恶意脚本 | 输出编码 |
| 中间人攻击 | 拦截通信 | 加密传输（HTTPS） |
| 钓鱼攻击 | 伪造网站欺骗 | 安全意识教育 |

#### 2. 网络安全技术

- **防火墙**：控制网络访问，隔离内外网
- **加密技术**：对称加密（DES、AES）、非对称加密（RSA）
- **数字证书**：证明身份合法，CA认证
- **VPN**：虚拟专用网络，加密远程连接
