## 计算机系统组成

### 一、计算机系统概述

**计算机系统由硬件系统和软件系统两大部分组成。** 硬件是计算机的物理实体，软件是计算机系统中的程序、数据和文档的集合。

```
计算机系统
├── 硬件系统
│   ├── 主机
│   │   ├── CPU（运算器 + 控制器）
│   │   └── 内存储器（主存）
│   └── 外部设备
│       ├── 外存储器（辅存）
│       ├── 输入设备
│       └── 输出设备
└── 软件系统
    ├── 系统软件（操作系统、编译程序等）
    └── 应用软件（办公软件、浏览器等）
```

### 二、冯·诺依曼体系结构

#### 1. 核心思想

数学家冯·诺依曼于1946年提出"存储程序"和"程序控制"的思想，确定了现代计算机的基本结构。

**冯·诺依曼体系结构三大核心思想：**
1. 计算机由运算器、控制器、存储器、输入设备和输出设备五大部件组成
2. 指令和数据以二进制形式存储在存储器中
3. 计算机按照程序顺序自动执行

#### 2. 五大部件功能详解

**（1）运算器（ALU）**
- 功能：进行算术运算和逻辑运算
- 组成：算术逻辑单元（ALU）、累加寄存器、数据缓冲寄存器、状态寄存器
- 核心性能指标：字长（一次能处理数据的二进制位数）

**（2）控制器（CU）**
- 功能：分析和执行指令，统一指挥计算机各部件协调工作
- 组成：程序计数器（PC）、指令寄存器（IR）、指令译码器（ID）、时序产生器、操作控制器
- 工作过程：取指令 → 分析指令 → 执行指令

**（3）存储器**
- 功能：存储程序和数据
- 分类：
  - **内存（主存）**：直接与CPU交换数据，速度快，容量小，断电信息丢失（RAM）
    - RAM（随机存取存储器）：可读可写，断电丢失
    - ROM（只读存储器）：只能读，断电不丢失
  - **外存（辅存）**：间接与CPU交换数据，速度慢，容量大，断电不丢失
    - 硬盘（HDD/SSD）、U盘、光盘等

**（4）输入设备**
- 功能：将程序和数据输入计算机
- 常见设备：键盘、鼠标、扫描仪、麦克风、摄像头、触摸屏等

**（5）输出设备**
- 功能：将计算机处理结果输出给用户
- 常见设备：显示器、打印机、音箱、绘图仪等

### 三、CPU（中央处理器）

**CPU = 运算器 + 控制器**，是计算机的核心部件。

#### 1. CPU的主要性能指标

| 指标 | 含义 | 说明 |
|------|------|------|
| 主频 | CPU内核工作的时钟频率 | 单位 GHz，主频越高，运算速度越快 |
| 字长 | CPU一次能处理的数据位数 | 32位/64位 |
| 核心数 | CPU芯片中包含的处理器核心数量 | 多核CPU |
| 缓存 | CPU内部的快速存储器 | L1 > L2 > L3，速度递减，容量递增 |

#### 2. 指令周期

CPU执行一条指令的过程称为指令周期，包含：
- **取指周期**：从内存取出指令
- **执行周期**：执行指令操作

### 四、总线结构

**总线是计算机各部件之间传输信息的公共通道。**

| 总线类型 | 传输内容 | 特点 |
|----------|---------|------|
| 数据总线（DB） | 数据信息 | 双向传输，宽度决定每次传输的数据量 |
| 地址总线（AB） | 地址信息 | 单向传输，宽度决定可寻址的内存空间 |
| 控制总线（CB） | 控制信号 | 每根线单向，整体可视为双向 |

### 五、存储系统层次结构

```
    ┌──────────┐
    │  寄存器   │ ← CPU内部，速度最快，容量最小
    ├──────────┤
    │   Cache   │ ← 高速缓存，L1/L2/L3
    ├──────────┤
    │  内存/RAM │ ← 主存储器
    ├──────────┤
    │  外存/硬盘 │ ← 辅助存储器，速度最慢，容量最大
    └──────────┘
    速度越快，容量越小，价格越贵（自上而下）
```

**Cache（高速缓存）** 位于CPU和内存之间，利用程序访问的局部性原理（时间局部性+空间局部性），提高CPU访问数据的速度。

### 六、软件系统

#### 1. 系统软件

- **操作系统（OS）**：管理计算机硬件和软件资源的核心软件（Windows、Linux、macOS）
- **语言处理程序**：编译程序、解释程序、汇编程序
- **数据库管理系统**：MySQL、Oracle、SQL Server
- **服务程序**：诊断程序、调试程序

#### 2. 应用软件

为解决特定应用领域问题而开发的软件，如：
- 办公软件：Word、Excel、PPT
- 图形图像软件：Photoshop、AutoCAD
- 浏览器：Chrome、Edge
